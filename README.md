# Maison Demmiz // Scent Hub

An ultra-premium, museum-grade digital archive and e-commerce platform dedicated to rare perfume extraits, vault-sourced vintage releases, and hand-poured custom decants. Built with an avant-garde, architectural grid aesthetic matching high-end design journals.

---

## 💎 Core Features

* **Dynamic Tri-Design Hero:** An optimized, interactive multi-layout loop that smoothly shifts between three distinct premium layout frameworks (Centered Editorial, Asymmetrical Split, and Minimal Typographic Watermark).
* **Architectural Bento Grid:** A sophisticated category navigation matrix utilizing variable grid coordinate spans (`lg:col-span-8`, `lg:col-span-4`) to break standard layout templates.
* **Technical Sizing & Volumetric Matrix:** Translates fluid ounces into practical customer use cases (e.g., spray output counts for 2ml, 5ml, and 10ml travel vials).
* **Dual Identity Palette:** Native, fully fluid transitions between **Purple (Light Mode)** and **Amber/Gold (Dark Mode)** brand states.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js 14/15](https://nextjs.org/) (App Router, Client Component state handling)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Fluid utility classes, custom animation delays, aspect-ratio controls)
* **Icons:** [Lucide React](https://lucide.dev/) (Ultra-light technical line vectors)
* **Fonts:** System Sans paired with serif elements (`Playfair Display`, `Didot`) for editorial contrast
